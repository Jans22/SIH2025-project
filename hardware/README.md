# Hardware

This directory contains the hardware documentation for the Smart Pesticide Sprayer prototype.

## Contents

### prototype-photos/

Photographs of the assembled prototype, enclosure, carriage mechanism, camera arrangement and spraying assembly.

### mechanical-design/

Mechanical dimensions and additional mechanical documentation.

### circuit-diagrams/

Electrical wiring and circuit diagrams for the motor driver and pump driver.

## Prototype

The prototype integrates:

- Raspberry Pi
- Camera
- Arduino
- L298N motor driver
- DC motor
- 12 V diaphragm pump
- Servo motor
- Pump driver circuit
- Cable-mounted carriage
- Custom enclosure
