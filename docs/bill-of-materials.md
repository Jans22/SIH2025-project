# Bill of Materials

## 1. Overview
This document lists the major electronic, mechanical and sensing components used in the Smart Pesticide Sprayer prototype.

## 2. Electronics and Control
| Component | Purpose |

| Raspberry Pi | Image capture, processing and system control |
| Raspberry Pi Camera | Crop image acquisition |
| Arduino | Motor and pump control |
| L298N Motor Driver | DC motor control |
| DC Motor | Cable-mounted carriage movement |
| 12 V Diaphragm Pump | Pesticide/liquid spraying |
| Servo Motor | Spraying nozzle positioning |
| 2N2222A NPN Transistor | Pump switching |
| 1N4007 Diode | Flyback protection for pump |
| 1 kΩ Resistor | Transistor base current limiting |
| 12 V Power Supply | Motor and pump power |

## 3. Mechanical Components

| Component | Purpose |

| Prototype enclosure | Houses electronics |
| Cable-mounted carriage | Provides movement along cable |
| Cable | Supports carriage movement |
| Spraying nozzle | Directs liquid spray |
| Tubing | Transfers liquid from pump to nozzle |

## 4. Camera and Sensing
| Component | Purpose |

| Raspberry Pi Camera | Captures crop images |
| Servo-mounted camera/nozzle mechanism | Allows positioning of the system |

## 5. Notes
The component list represents the hardware used in the documented prototype. Additional components may be added as the system is further developed.
