# Smart Pesticide Sprayer — PCB Design

## Overview
This folder contains the PCB design developed for our Smart Pesticide Sprayer project as part of **Smart India Hackathon (SIH) 2025** by Team TheVisioneers.

The PCB was designed using EasyEDA to organize the power distribution and embedded control interfaces of the sprayer system.

## Design Features
- Raspberry Pi GPIO interface for embedded control
- L298N motor-driver interface for carriage movement
- MOSFET-based switching circuits for the sprayer pump and solenoid valve
- 12V power input and external buck-converter interfaces
- Dedicated connectors for the carriage motor, pump, solenoid valve, and servo
- Schematic capture, component placement, PCB routing, and 2D/3D visualization

## Project Status
**Educational design — not fabricated or electrically tested.**

The design is shared for documentation and learning purposes. Design-rule-check results indicate layout-rule status only and do not establish electrical correctness or hardware validation.
